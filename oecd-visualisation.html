Project Overview

This project presents an interactive data visualisation dashboard built to explore global development indicators across 40+ countries. The dashboard allows users to compare countries through multiple metrics including life satisfcation, water quality, air pollution, life expectancy and more.

Data Processing & Methodology

  • Data wrangling performed using Python and Pandas
  • Cleaning and preprocessing conducted in Jupyter Notebooks
  • Dataset transformation for visual encoding
  • Integration with GeoPandas for world map visualisation
  • Metrics transformed to show measurement unit

Key Features

  • Interactive world map with country selection
  • Comparative visual analytics across multiple indicators
  • Dynamic filtering and user-driven exploration
  • Cleaned dataset pipeline from raw Excel data
  • Exported as standalone HTML file for simple embeddings

Technologies Used

Python Pandas Altair GeoPandas Jupyter Excel
