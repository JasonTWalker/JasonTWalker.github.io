Handling Missing Data with Statistical and ML-Based Imputation

This project explores different data imputation techniques. The notebook compares statistical and machine-learning based approaches, evaluating their performance against the complete dataset.

View GitHub Repository

Project Overview

This project explores the impact of different imputation techniques on a real-world dataset containing naturally occurring missing values (California Housing). The aim was to evaluate how statistical and machine learning-based imputers affect dataset structure, feature relationships, and downstream model performance.

Exploratory Data Analysis (EDA) was conducted to assess missingness patterns and feature correlations, using scatter plot matrices and correlation analysis to guide the choice of imputation strategies. Feature engineering was also applied to cumulative variables such as total_rooms, total_bedrooms, and population by converting them into per-household averages to better reflect the underlying data structure.

Multiple imputation approaches were implemented and systematically benchmarked against a cleaned baseline dataset using regression metrics (R², MAE, and MSE). This allowed evaluation of how each method influenced predictive performance rather than relying solely on visual distribution comparisons.

Data Processing & Methodology

  • Analysis of missing data patterns in a real-world dataset
  • Correlation-guided imputation strategy using scatter plot matrices
  • Feature engineering on cumulative housing variables to improve data representation
  • Implementation of KNN Imputation and MICE (Iterative Imputers)
  • Comparison of different MICE estimators (Bayesian Ridge and Decision Tree)
  • Benchmarking imputed datasets against a cleaned baseline
  • Evaluation using regression metrics (R², MAE, MSE)
  • Visual validation of feature distributions and relationships before and after imputation

Why This Matters

Missing data is a common challenge in real-world datasets and can significantly affect analytical reliability and model performance. Different imputation techniques make different statistical assumptions, which may not always align with the structure and constraints of the data.

This project demonstrates that there is no one-size-fits-all approach to imputation. For example, Bayesian Ridge imputation occasionally produced unrealistic negative values for inherently non-negative housing features, highlighting the limitations of linear model-based estimators when applied to bounded real-world data. Despite this, comparative benchmarking showed that different methods preserved dataset structure and predictive performance to varying degrees.

By validating imputation outcomes using both visual analysis and regression-based evaluation, the project reflects a data preprocessing workflow where method selection is guided by data structure, model assumptions, and performance rather than default imputation choices.
